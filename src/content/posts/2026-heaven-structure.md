**TL;DR**: 歌詞資料は「4/4 BPM:125」と記している。歌詞は、冒頭の4行が最後にそのまま戻る、円環の作りになっている。

## 基本スペック

歌詞資料の冒頭には「4/4 BPM:125」とある。4分の4拍子で、1分間に125拍。目安としては、歩くより少し速く、走るほどではないテンポだ。

## 歌詞のまとまり

歌詞資料の空行で区切ると、おおよそ次のまとまりに分けられる。

| まとまり | 内容 |
| --- | --- |
| A | 明け方、Tシャツ、「あぁ、夏だ」、スヌーズ |
| B | 朝焼けに染まる五畳半 |
| C | 「本当はどこまでだって行ける部屋では」 |
| D | 書きかけたレター / 流れ込んだブルー |
| E | 蝉、鏡、「旅は続くよ」、「足りないものは何だろう」(空行で2つに分かれる) |
| F | 束の間 涼風 五畳半、「開かずの扉」 |
| G | 明日が割り込む、真夜中 |
| H | 先送りした結末、「この世の果てまで連れ出して」 |
| C' | 「本当はどこまでだって」(繰り返し)、始まる夏の日 |
| D' | 書き出したレター / 流れ込んだブルー |
| A' | 冒頭の4行の再現 |

C→C'、D→D'のように、対応する場所が2つずつある。ただし、どの部分がサビにあたるかは、歌詞資料だけでは判断できない。メロディを聴いて判断する必要がある。

## 変わる部分と、変わらない部分

C'は、Cの2行(「本当はどこまでだって行ける部屋では/大袈裟過ぎることも許されているのだ」)に、「どこまでだって広がる部屋から/始まる夏の日/笑えるくらいに下手でも」の3行が続く形になっている。また、歌詞資料では「大袈裟すぎる」(前半)と「大袈裟過ぎる」(後半)のように、ひらがなと漢字で表記が違う。読みは同じだ。

D と D' は、「書きかけた」と「書き出した」だけが違う。([詳しくは別記事](/posts/2026-heaven-letter-blue/))

## 最後の4行

最後のA'は、冒頭の4行と、歌詞資料の上では同じ言葉が戻ってくる。

> 明け方の空気と
> 汗ばんだTシャツ
> 脱ぎ捨てた後で
> 「あぁ、夏だ」と気付いた

聴くときには、1回目より、「気付いた」の重みが変わるかもしれない。曲の中で、手紙が動き出し、部屋が広がった後に戻ってくるからだ。この印象は、聴き手の感じ方による。
